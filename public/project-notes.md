# 蚌壳 SHELL · 项目说明

一句话：通过人机协作构建的移动优先视觉日记 PWA，将图像、短句和当时的感受放在同一个私人空间。

## 想解决什么

截图在相册，文字在备忘录，触动自己的理由很少一起留下。蚌壳让图文成为一枚记录，同时支持随意浏览和有序回看，并把愿意公开的摘录导出为卡片。

## 已经做了什么

React 19 + Vite 8；雾中开屏、培养皿每日句子、图文记录、本地持久化、拼贴/网格/档案、1080 × 1440 PNG 卡片、PWA 基础、独立产品案例页、CI 与 GitHub Pages 配置。

## 人机协作的方式

人提出场景、审美、优先级和验收标准；AI 编程助手协助拆解、实现、迭代与验证。关键决策是把完整宠物养成和真实 AI 放到后续，先完成记录—回看—分享。

## 当前边界

可交互原型；AI 旁注、简笔画和推荐为预设示例，无模型调用。电影识别、账号、云同步、真实养成尚未实现。localStorage 配额有限，没有备份，不用于重要内容的唯一存储。暂无用户规模或商业指标。

## 下一步

优先完成可靠图片存储、备份和设备验证，再用小规模试用判断是否需要 AI。后续接入通过服务端代理、用户按次授权和可信作品检索实现。

公开样例为虚构文字与原创 SVG，不包含原始私人日记和电影截图。项目角色适合表述为“独立产品设计与 AI 协作开发”。
