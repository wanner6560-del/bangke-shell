# 公开素材与数据说明

| 文件 | 来源 | 说明 |
| --- | --- | --- |
| public/images/*.svg | 本项目绘制的矢量插画 | 雨站、隧道、雾中水域、黄伞、珍珠、湖面；未引用电影截图或外链位图 |
| public/shell-icon.svg | 本项目产品图标 | 壳形线条 |
| docs/assets/cover.svg | 本项目绘制 | GitHub 说明页封面 |
| docs/assets/*.png | 本项目页面截图 | 来自虚构公开示例，不包含用户本地记录 |
| public/social-card.png | 展示页首页截图 | 用于分享链接的预览图 |
| src/sample-data.js | 为公开 Demo 创作的虚构文字 | 无原始私人日记内容 |
| 作品推荐清单 | 公开作品名称与创作者名 | 仅作预设推荐示例，不复制诗歌正文、电影画面或音频 |
| 字体 | 操作系统字体栈 | 不打包商业字体，不加载字体 CDN |

原始用户素材和日记不纳入公开仓库。用户后续导入的内容由用户自行判断适用的权利和分享范围；卡片署名不意味着平台授予了素材版权。

本项目使用的 React、Vite、Oxlint 等依赖遵循各自许可证；项目自身的权利说明见根目录 RIGHTS.md。
