## 当前边界

这是可交互原型。AI 旁注、简笔画和相似作品推荐为预设示例，没有真实模型调用；电影识别、账号、云同步、养成尚未实现。localStorage 容量有限且尚无备份机制。

代码公开用于作品展示与技术评审，当前未授予通用开源许可；复用请参照 RIGHTS.md 联系维护者。

附件为明确文件清单生成的源代码发布包，不包含私人日记、原始参考截图或其他个人项目。
